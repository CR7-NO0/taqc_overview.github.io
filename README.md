# TAQC: Research Overview

This repository hosts a concise overview website for the research paper **"Autonomous UUV Control for Multi-Waypoint Tracking through Distributional Reinforcement Learning."**

The website provides a summarized presentation of the research motivation, proposed TAQC framework, experimental setup, and key results, along with demonstration videos of UUV trajectory tracking and six simulated seabed scenarios.

The content is intended for research presentation and visualization rather than full paper reproduction.

**Website:** [https://cr7-n00.github.io/taqc_overview.github.io/](https://cr7-no0.github.io/taqc_overview.github.io/index.html)

**Status:** The manuscript is currently under review. Data and code are available upon reasonable request.
